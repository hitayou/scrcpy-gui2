# scrcpy-gui

Современный GUI для scrcpy с поддержкой Material Design 3.

## Возможности

- **Material Design 3** - Красивый современный интерфейс
- **Тёмная/Светлая тема** - Бесшовное переключение тем
- **Мультиязычность** - Поддержка английского и русского
- **USB и WiFi подключение** - Подключение через USB или TCP/IP
- **Все опции scrcpy** - Полный доступ к настройкам видео, аудио, записи, управления
- **Встроенные обучающие материалы** - Пошаговые руководства по подключению USB и WiFi
- **Одна кнопка управления** - Запуск/остановка трансляции одной кнопкой
- **Адаптивный дизайн** - Интерфейс подстраивается под размер экрана
- **Сохранение конфигурации** - Сохранение и загрузка настроек

## Требования

- Python 3.8+
- PySide6
- Установленный scrcpy в системе
- ADB (Android Debug Bridge)

## Установка

### Windows

1. Установите Python 3.8+ с https://python.org
2. Откройте Command Prompt в папке проекта
3. Выполните: `build.bat`
4. Исполняемый файл будет создан в папке `dist`

### Linux/macOS

```bash
chmod +x build.sh
./build.sh
```

### Ручная установка

```bash
pip install PySide6
python scrcpy_gui.py
```

## Использование

1. **Подключение устройства**:
   - Режим USB: Подключите через USB кабель, нажмите Обновить
   - Режим WiFi: Введите IP адрес и порт, нажмите Подключить

2. **Настройка параметров**:
   - Видео: Разрешение, битрейт, FPS, ориентация
   - Аудио: Битрейт, опции передачи
   - Запись: Формат (MP4/MKV), путь сохранения
   - Управление: Текстовый ввод, геймпад, касания
   - Окно: Полный экран, всегда сверху, без рамок
   - Дополнительно: Пути ADB/scrcpy, уровень логов, язык, тема

3. **Запуск трансляции**: Нажмите кнопку "Запустить"

4. **Остановка трансляции**: Нажмите кнопку "Остановить"

## Горячие клавиши (в окне scrcpy)

- `Ctrl+G` - Переключить полный экран
- `Ctrl+H` - Домой
- `Ctrl+B` - Назад
- `Ctrl+S` - Скриншот
- `Ctrl+O` - Выключить экран
- `Ctrl+N` - Раскрыть панель уведомлений

## Конфигурация

Настройки автоматически сохраняются в `~/.scrcpy-gui/config.json`
