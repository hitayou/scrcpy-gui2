# Как использовать scrcpy-gui

## Установка

### Windows

1. Установите Python 3.8+ с https://python.org
2. Запустите `build.bat` для сборки приложения
3. Запустите `dist\run.bat` для запуска приложения

Или вручную:
```cmd
pip install PySide6
python scrcpy_gui.py
```

### Linux

```bash
chmod +x build.sh
./build.sh
./dist/run.sh
```

Или вручную:
```bash
pip3 install PySide6
python3 scrcpy_gui.py
```

## Подключение по USB

1. Включите опции разработчика на Android устройстве
   - Настройки → О телефоне
   - Нажмите 7 раз на "Номер сборки"
2. Включите отладку по USB
   - Настройки → Система → Для разработчиков
   - Включите "Отладка по USB"
3. Подключите устройство через USB кабель
4. Примите запрос отладки на устройстве
5. Нажмите "Обновить устройства" в scrcpy-gui
6. Выберите устройство и нажмите "Подключить"
7. Нажмите "Запустить зеркалирование"

## Подключение по WiFi

1. Сначала выполните настройку USB (см. выше)
2. Подключите устройство и компьютер к одной WiFi сети
3. Узнайте IP адрес устройства:
   - Настройки → О телефоне → Статус
   - Или: `adb shell ip route | awk '{print $9}'`
4. Включите режим TCP/IP: `adb tcpip 5555`
5. Отсоедините USB кабель
6. Введите IP адрес в scrcpy-gui и нажмите "Подключить"
7. Нажмите "Запустить зеркалирование"

## Настройки

### Видео
- Максимальное разрешение (0 = без ограничений)
- Битрейт (Мбит/с)
- Максимум FPS
- ID дисплея
- Видео кодек (h264, h265, av1)
- Обрезка видео

### Аудио
- Включить/выключить аудио
- Битрейт аудио
- Аудио кодек (opus, aac, flac, raw)
- Источник аудио (output, playback, mic)

### Запись
- Включить запись
- Формат записи (mp4, mkv)
- Путь к файлу
- Без воспроизведения видео (только запись)
- Без воспроизведения аудио (только запись)

### Управление
- Предпочитать текстовый ввод
- Сырые события клавиш
- Поддержка геймпада
- Режим привязки мыши

### Окно
- Заголовок окна
- Всегда сверху
- Без рамок
- Полноэкранный запуск
- Позиция окна (X, Y)
- Размер окна (Ширина, Высота)
- Цвет фона
- Отключить скринсейвер

### Дополнительно
- Ограничение по времени
- Выключить экран устройства
- Выключить при закрытии
- Не включать
- Завершить ADB при закрытии
- Принудительная переадресация ADB
- Туннель хост/порт

## Горячие клавиши (в окне scrcpy)

- `Alt+F` - Полноэкранный режим
- `Правая кнопка мыши` - Назад
- `Средняя кнопка мыши` - Домой
- `Ctrl+C` - Копировать
- `Ctrl+V` - Вставить

## Конфигурация

Настройки сохраняются в `~/.scrcpy-gui/config.json`

Можно вручную сохранять/загружать конфигурации во вкладке "Дополнительно".

## Решение проблем

### "Устройства не найдены"
- Проверьте что отладка по USB включена
- Попробуйте другой USB кабель
- Установите драйверы USB (Windows)
- Выполните `adb devices` для проверки

### "Не удалось подключиться"
- Проверьте что устройство и компьютер в одной сети
- Проверьте правильность IP адреса
- Убедитесь что порт 5555 не заблокирован фаерволом
- Попробуйте `adb kill-server` и переподключитесь

### "scrcpy не найден"
- Установите scrcpy с https://github.com/Genymobile/scrcpy
- Убедитесь что scrcpy в PATH
